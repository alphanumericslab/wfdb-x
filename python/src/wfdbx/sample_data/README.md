# Sample data

`100s` is the sample record of the WFDB Software Package (its `data/`
directory): the first minute of record 100 of the MIT-BIH Arrhythmia
Database, two ECG signals (MLII and V5) sampled at 360 Hz, with the
reference beat annotations (annotator `atr`). It is included so that the
examples and notebooks run without a network connection.

The MIT-BIH Arrhythmia Database is available from PhysioNet
(https://physionet.org/content/mitdb/); please cite it as described there
when you use it.
